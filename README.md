# ระบบวัตถุดิบห้องครัว (SQL Server)

## ติดตั้ง
1. ติดตั้ง/เปิด SQL Server และเปิดการเชื่อมต่อ TCP/IP ให้ Node.js เข้าถึงได้
2. คัดลอก `.env.example` เป็น `.env` แล้วกรอกค่าเชื่อมต่อ (`DB_SERVER`, `DB_PORT`, `DB_NAME`, `DB_USER`, `DB_PASSWORD`) พร้อม `JWT_SECRET` และ `ADMIN_PASSWORD`
   - SQL Server ปกติใช้ `DB_SERVER=localhost` และ `DB_PORT=1433`
   - SQL Server Express แบบ named instance ใช้ `DB_SERVER=localhost`, `DB_INSTANCE=SQLEXPRESS` และเว้น `DB_PORT` ว่าง
3. รัน `npm install` แล้ว `npm start` ตัวแอปจะเชื่อม SQL Server และสร้างฐานข้อมูล/ตารางที่ยังไม่มีให้โดยอัตโนมัติ จากนั้นเปิด http://localhost:3000

การเริ่มครั้งแรก บัญชี SQL ต้องมีสิทธิ์สร้างฐานข้อมูลและตาราง หากสร้างฐานข้อมูลไว้แล้ว บัญชียังต้องมีสิทธิ์สร้างตารางในฐานข้อมูลนั้น ข้อมูลเดิมจะไม่ถูกลบเมื่อเปิดแอปหรือรัน `schema.sql` ซ้ำ

## สิทธิ์การเข้าถึง
- **แท็บฝ่ายจัดซื้อ**: ต้องล็อกอินด้วยบัญชี admin (เพิ่ม/แก้ไข/ลบ)
- **แท็บเชฟ**: ไม่ต้องล็อกอิน ดูสต็อกและเบิกได้ (ไม่แก้ไข/ลบรายการ)
- การตรวจสิทธิ์ทำที่เซิร์ฟเวอร์ ไม่ใช่แค่ซ่อนแท็บในหน้าเว็บ

## ก่อนใช้งานจริง
- ใช้ผ่าน HTTPS แล้วตั้ง `COOKIE_SECURE=true`
- เพราะหน้าเชฟไม่ต้องล็อกอิน ควรเปิดให้เข้าถึงเฉพาะเครือข่ายภายในร้าน/ครัว
- ควรใช้ SQL user ที่มีสิทธิ์เฉพาะฐานข้อมูลนี้ แทน `sa`
- ระบบสร้างหรืออัปเดตรหัสผ่านบัญชี admin จาก `ADMIN_USERNAME` และ `ADMIN_PASSWORD` ใน `.env` ทุกครั้งที่เริ่มแอป

## แจ้งเตือนเข้ากลุ่ม LINE
ขั้นตอนการทำงาน: เชฟกดเบิก (หักสต็อกทันที) -> แจ้งเข้ากลุ่ม -> ฝ่ายจัดซื้อกด "เตรียมเสร็จ" ในแท็บฝ่ายจัดซื้อ -> แจ้งเข้ากลุ่มอีกครั้ง

ตั้งค่า (LINE Notify ปิดบริการแล้ว จึงใช้ Messaging API):
1. สร้าง LINE Official Account แล้วเปิดใช้ Messaging API (Settings > Messaging API)
2. นำ Channel access token และ Channel secret ใส่ `.env`
3. ใน LINE Official Account Manager เปิดให้บัญชีเข้าร่วมแชทกลุ่มได้ แล้วเชิญบอทเข้ากลุ่มที่มีทั้งฝ่ายจัดซื้อและเชฟ
4. ตั้ง Webhook URL เป็น `https://โดเมนของคุณ/line/webhook` (ต้องเป็น HTTPS สาธารณะ ใช้ tunnel ชั่วคราวได้) แล้วพิมพ์ข้อความอะไรก็ได้ในกลุ่ม
5. ดู `LINE_GROUP_ID = C...` ในหน้าจอ console ของเซิร์ฟเวอร์ ใส่ใน `.env` แล้วรีสตาร์ท (หลังจากนั้นปิด webhook ได้)

ข้อควรรู้เรื่องโควต้า: LINE นับข้อความที่ส่งเข้ากลุ่มตามจำนวนสมาชิก (ส่ง 1 ข้อความเข้ากลุ่ม 10 คน = 10 ข้อความ)
ตรวจโควต้าของแพ็กเกจคุณใน LINE Official Account Manager ระบบจึงรวมรายการของเชฟคนเดียวกันที่ส่งใกล้กัน
เป็นข้อความเดียว และมีเพดาน `LINE_MAX_PER_HOUR` ถ้ายังไม่ตั้งค่า LINE ระบบจะแสดงข้อความใน console แทน

อัปเกรดจากเวอร์ชันก่อน: รัน `schema.sql` ซ้ำ (ข้อมูลเดิมไม่หาย)
